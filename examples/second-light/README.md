# second-light — the Deku Tree save-file repo

The machine that flew ocarina's second live session (2026-08-01
afternoon, hours after first light — full record:
`../../../oot-dojo/docs/21-second-light-2026-08-01.md`). First light
proved the server flies; second light proved the *loop*: three wakes
answered, three live brain surgeries, the first mind-authored behavior,
and a room cleared of babas by a graded body ported import-lines-only.

Run it:

```bash
python3 -m ocarina --repo examples/second-light
# then launch SoH; it connects out to 127.0.0.1:43384
# tools/drive.py is the hand-drive rig used to play the mind's role
```

The machine.yaml is a session fossil, kept deliberately: the demoted
damage wake (froze the game under a playing human twice in 21s → stage-2
journal, wake reserved for critical health), the removed overhead-lurker
(keyed on a ceiling skulltula no sighted player could know about — AJ's
fairness ruling, mid-session), and the seek→hunt clearing loop whose
`hunt-over` was rewired mid-flight after `wander_scan_v2` walked Link
out the front door in 3.5 seconds (an avoider sent to do a hunter's
job — its enemy veto steered it away from the mission, on spec).

behaviors/combat.py carries the session's two headline artifacts:
`deku_baba_v4` — the dojo's champion killer, ported with only its import
lines changed, three field kills for zero damage — and
`approach_baba_v1`, authored by the mind mid-play to close the seek gap.
Its grade line says UNGRADED and means it: both field successes found
the baba already in range, so its walking leg has never been tested.
Send it to the dojo before believing anything about it.

NOTE: this is a commissioning example, not a benchmark run. A real
playthrough repo starts empty (new repo = new kid) and grows its own
machine.
